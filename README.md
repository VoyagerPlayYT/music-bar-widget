## 🌟 Описание проекта

**Music Bar Desktop Widget** — это легкий, безрамочный и стильный виджет рабочего стола в стиле Glassmorphism (эффект матового полупрозрачного стекла с неоновыми градиентами). 

Виджет напрямую взаимодействует с ядром Windows через **Windows Media Control API (WinRT)**. Он считывает текущий воспроизводимый трек из любого источника (Яндекс Музыка, Spotify, YouTube в браузере, VK Музыка, AIMP, VLC) и выводит:
- 🖼 Название трека и исполнителя;
- 🎨 Настоящую обложку альбома из потока Windows;
- ⏱ Живой прогресс-бар с прошедшим и оставшимся временем;
- 📊 Анимированный звуковой эквалайзер;
- ⏯ Кнопки управления: Пауза / Плей, Предыдущий трек, Следующий трек;
- 📌 Режим «Поверх всех окон» (Always on Top);
- ⚡ Интерактивный демонстрационный режим для мгновенного показа без открытых сторонних плееров;
- 🖱 Свободное перемещение виджета перетаскиванием мыши в любое удобное место экрана.

## 🛠 Стек технологий

- **Язык**: Python 3.11+
- **Графический интерфейс**: PyQt6 (безрамочное окно, аппаратное сглаживание, кастомные QPainter градиенты, полупрозрачность WA_TranslucentBackground)
- **Системные интеграции**: `winrt-Windows.Media.Control`, `winrt-Windows.Storage.Streams`, `winrt-runtime` (нативный низкоуровневый WinRT API)
- **Асинхронность**: `asyncio` для неблокирующего чтения медиа-сессий Windows

## 🚀 Быстрый запуск

### Вариант 1: Запуск в один клик
Дважды щелкните по файлу:
```bash

```

### Вариант 2: Запуск через терминал


2. Запустите приложение:
```bash

```

## 🖥 Зачем этому проекту нужен выделенный сервер 24/7?

В домашней IT-инфраструктуре десктопный виджет — это клиентский фронтенд единой домашней аудиосистемы. Для полноценной автономной работы требуется круглосуточный домашний сервер:

1. **Центральный сервер домашней медиатеки (Plex / Navidrome / Jellyfin)**:
   - Вся музыка семьи, lossless-аудио и подкасты хранятся на выделенном сервере в RAID-массиве с круглосуточным доступом.
   - Сервер транслирует музыку на все устройства в доме (ПК, умные колонки, телефоны) без необходимости держать рабочий компьютер постоянно включенным.
2. **Multi-Room синхронизация и Webhook-хаб**:
   - При переходе из комнаты в комнату сервер по MQTT передает состояние воспроизведения, позволяя бесшовно переносить звук.
   - Виджет отправляет команды на сервер для управления домашними колонками и умным домом.
3. **Кэширование метаданных и обложек высокого разрешения**:
   - Сервер 24/7 парсит базы Last.fm, Spotify Web API и MusicBrainz, генерируя тексты песен (lyrics) и HD-обложки для всех клиентов локальной сети без задержек.
